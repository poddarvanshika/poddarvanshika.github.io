Ever felt overwhelmed while applying for a credit card?

Project overview

This project explores how credit-card applications can be simplified. From card discovery to applying and progress tracking, it introduces an agentic experience that adapts to user’s needs.

My role

Designed the core activation gesture to interact with the AI. My work extended from researching adaptive interfaces and credit card processes to building high-fidelity UI and prototype.

Problem

Traditional credit onboarding overwhelms users with a catalogue of cards without personal context, followed by an opaque review process with no clear next steps.

  • Decision fatigue
  • Pending application status
  • Lack of context

Process

Understanding credit-card onboarding, from verification to credit checks.

Reviewed regulatory requirements, verification and credit checks, and differences between new and existing customers.

Insights

Existing context can reduce repeated input

This informed pre-filled details that users review and confirm, while keeping required verification steps visible.

Regulatory requirements shape the flow

I studied identity-verification requirements, soft and hard credit enquiries, and their credit-score implications. These shaped the required checks, explanations and consent points in the app.

To identify gaps in the existing credit journeys, I evaluated leading US banking onboarding flows.

Insights

Personalisation needs context

The gaps in card discovery informed recommendations based on spending behaviour, with an explanation of why each card fits.

Application status needs a next step

Opaque tracking informed clearer pending states and guidance on what the user can do next.

Based on my research into existing processes, I designed the user journey for Finora: from requesting a credit card to the application outcome.

Insights

The AI needs permission to act

In a financial application, the AI assists while the user stays in control. I added explicit authorisation before the hard credit enquiry and application submission.

The journey needs to handle edge cases

Credit-card applications are not always straightforward, and approval is not always instant. I mapped the different outcomes and edge cases to account for delays and additional checks.

I mapped out what happens when a credit-card application isn’t immediately approved.

In the prototype, a customer applies after moving, but their documents still show their old address, leaving the application pending verification. I chose this research-informed scenario as a realistic, easy-to-follow edge case to show how the app explains a delay and guides the next step.

Insights

A pending status needs an explanation and a next step

This informed a clear reason for the delay, a guided document request and visible application progress.

Personalisation should use the customer’s context

This informed a proactive AI agent that uses information already available to the bank, such as statements and spending history, to tailor card suggestions to the customer.

I used research insights and existing bank UIs to organise Finora’s screens and navigation.

Insights

Keep everyday banking easy to find

Home, card management and settings remain separate from the credit-card journey.

Give the credit-card journey a clear route

The financial concierge groups discovery, recommendations and application steps in one place.

Moved beyond static screens to explore agentic interfaces that adapt to user intent and anticipate their needs.

Using financial context, spending behaviour and goals, we can provide proactive, personalised recommendations and screen flows.

Insights

Drawback of agentic adaptive interface

Loss of spatial predictability due to changing layouts can disrupt learned patterns.

How it was addressed

A consistent banking dashboard, with distinct floating windows for AI generated flows.

Solution

Finora: An agent that simplifies complex banking journeys through intelligent guidance, automation, and proactive support.

What makes Finora different?

Built around four principles

  • Hyper-personalized Dashboard
  • Multitasking: Floating AI Windows
  • Proactive AI Recommendations
  • Adaptive Agentic UI
